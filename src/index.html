新手指南

辞之漏辩论计时器

如何使用计时器

  • 顶部填写辩题与正反方队名，中央左右两栏分别是两队的剩余时间。
  • 点「开始」或按 Space 启动，双方各自独立倒计时；再次点击即暂停。
  • 剩余 30 秒、5 秒与归零时会响提示音；归零的一栏停在 00:00.0 并变红。
  • 「重置」回到当前环节预设时长，「交换正反方」互换两队的名字与剩余时间。
  • 点环节芯片可切换立论、驳论、自由辩论等，切换会停表并加载新时长。

如何选择赛制与导入辩词

  • 选择赛制：点底部「选择赛制」下拉，直接选「华辩标准赛制」或「英国议会制 (BP)」；选「导入自定义 JSON...」可导入自己的赛制文件。
  • 自定义 JSON 格式是数组，例如 [{"name":"立论","seconds":180}]；也支持双方不同时长 {"name":"自由辩论","seconds":{"pro":240,"con":180}}。
  • 加载后环节列表出现在计时区上方，当前环节高亮，点击即可切换。
  • 导入辩词：点「导入辩词素材」，选择 .txt 或 .md，文件会按空行切分成片段。
  • 片段保存在本机，供文案工坊使用；左下角显示「素材：已导入 N 个片段」。

如何使用文案工坊

  • 点「文案工坊」打开工作台，左侧是已导入的辩词片段。
  • 第一次使用先点「接口设置」，填 Base URL、API Key 与模型（如 https://api.deepseek.com/v1 与 deepseek-chat）。
  • 选中片段，输入写作指令（「压缩到 80 字」「改为质询口吻」），点「处理」。
  • 生成内容逐字流式出现；点「接受」替换原文，点「撤销」回退到替换前。
  • 请求由 Rust 发出，Key 只保存在本机应用数据里。

如何使用 PPT / 图片背景

  • 点「导入 PPT 背景」，可以选 .pdf、.pptx（需要本机安装 LibreOffice），或直接选一张图片（.png / .jpg / .gif / .webp 等）作为背景。
  • PPT / PDF 会铺满窗口作为背景，计时器 UI 浮在上面，文字保持可读；单张图片会铺满全屏。
  • PPT / PDF 用 ← → 或点击画面左右半区翻页，右下角显示当前页码；图片无翻页。
  • 「背景设置」里可以调遮罩浓度 0–60%，并切换计时数字的黑 / 白描边。
  • 想恢复原样：打开「背景设置」点「移除背景」。

如何使用 AI 工具

  • 「AI 写辩词」提供豆包、DeepSeek、通义千问三份提示词，复制后到网页版粘贴使用。
  • 「AI 生成 PPT」提供 Gamma、夸克 PPT、豆包，适合先生成大纲或整套幻灯片。
  • 每张卡片底部的「去网页版」会用系统浏览器打开对应网站。
  • 应用不调用这些服务的接口，也不保存你的对话内容。
  • 生成好的 PPT 导出为 PDF 后，可用「导入 PPT 背景」带回本应用。
